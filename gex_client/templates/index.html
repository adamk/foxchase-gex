One-time setup

Connect your Schwab developer app

Your app credentials and OAuth token stay on this computer. They are never sent to Foxchase Trading.

  1. Create an Individual Developer app at developer.schwab.com with Market Data Production.
  2. Set its callback URL to exactly https://127.0.0.1 and wait for Ready for use.
  3. Copy .env.example to .env, then add the app key and secret.
  4. Run python -m gex_client.login, authorize Schwab, and paste the full redirect URL.
  5. Run python run.py again.
